# TONchaser Demo (Railway)

## Deploy na Railway
1. Utwórz nowe repo na GitHub i wrzuć te pliki.
2. Połącz Railway z repozytorium.
3. Ustaw w Railway Variables:
   - BOT_TOKEN
   - ADGEM_APPID=30887
   - USE_WEBHOOK=true
   - WEBHOOK_SECRET=supersecret_123
   - PUBLIC_BASE_URL=https://<twoja-nazwa>.up.railway.app
4. Deploy i gotowe 🚀
